======================================================================
เอกสารรายงานการปรับปรุงระบบทั้งหมดในวันนี้ (สรุปอย่างละเอียด)
======================================================================

เอกสารนี้ระบุการเปลี่ยนแปลง โครงสร้างโค้ด ไฟล์ และฐานข้อมูลทั้งหมดที่ได้ร่วมกันพัฒนาในวันนี้
โดยครอบคลุมทั้งฝั่ง Frontend (React + TypeScript), Backend (PHP + Routing), MySQL Database 
และการทำ Refactor โครงสร้างตารางและตัวแปรหลังบ้านให้อ่านง่ายและถูกต้องตามหลักวิศวกรรมซอฟต์แวร์

----------------------------------------------------------------------
📂 ส่วนที่ 1: การลงทะเบียนเส้นทางและตัวจัดการหลังบ้าน (Backend Router & Core API)
----------------------------------------------------------------------

1.1 ตัวจัดการเส้นทางหลัก (backend/src/index.php)
----------------------------------------------------------------------
- ลงทะเบียนเส้นทาง (Router) สำหรับหน้าจอ `CoursesPage` เพื่อจัดการคำขอดึงรายวิชา, รายชื่อนักศึกษา, และอัปเดตเกรด
- โค้ดที่เพิ่มเข้าไปใน switch ($page):
  * case 'get_courses':
  * case 'get_students':
  * case 'update_grade':
    (ดึงไฟล์ require_once 'components/Teacher/CoursesPage/api.php' มาจัดการคำขอ)

1.2 หน้าเว็บ API กลาง (backend/src/components/Teacher/CoursesPage/api.php)
----------------------------------------------------------------------
- ปรับระบบ API Routing:
  * แก้ไข $action = $_GET['action'] ?? $_GET['page'] ?? ''; เพื่อรองรับตัวแปร `page` ที่ถูกยิงมาจาก Router หลัก
- แก้บั๊ก CORS Policy (Credentials Block):
  * นำบล็อกการประกาศ Headers ซ้ำซ้อนและจำกัด (เช่น `Access-Control-Allow-Origin: *`) ออกจากไฟล์ย่อย
  * ให้สัญญาณ OPTIONS ยิงเข้าไปจัดการที่ index.php เพื่อให้สอดรับกับการส่ง session/cookie ตรวจจับสิทธิ์ผู้ใช้

----------------------------------------------------------------------
📂 ส่วนที่ 2: ปรับปรุงหน้าจอรายวิชาและการกรอกเกรดฝั่ง Frontend (React TypeScript)
----------------------------------------------------------------------

ไฟล์ที่แก้ไข: frontend/src/components/pages/Teacher/CoursesPage.tsx

2.1 การนำเข้าชุดคำสั่ง (Imports)
----------------------------------------------------------------------
- นำเข้า `useState`, `useEffect`, และ `useCallback` เพื่อบริหารจัดการสเตตแบบมีประสิทธิภาพ
- นำเข้า Axios client (`api` จาก `@/lib/axios`) สำหรับเรียกใช้ API หลังบ้าน

2.2 พัฒนาระบบแสดงผลแบบ Real-time (Dynamic State)
----------------------------------------------------------------------
- เอาข้อมูลรายวิชาและคะแนนจำลอง (Mockup) ออกทั้งหมด และจัดสรร State เปล่าเพื่อรอรับข้อมูลจากฐานข้อมูล:
  * const [courses, setCourses] = useState<Course[]>([]);
  * const [studentGrades, setStudentGrades] = useState<StudentGrade[]>([]);
  * const [loading, setLoading] = useState(false);

2.3 ฟังก์ชันการดึงและบันทึกข้อมูลเกรดจริง
----------------------------------------------------------------------
- ฟังก์ชัน fetchCourses(): เรียก GET '/index.php?page=get_courses' โหลดวิชาสอนทั้งหมดของอาจารย์ที่กำลังล็อกอิน
- ฟังก์ชัน openGradeDialog(course, viewMode): เรียก GET `/index.php?page=get_students&course_id=${course.id}` เพื่อดึงข้อมูลเด็กที่ลงทะเบียนจริงในวิชานั้นๆ พร้อมแบ่งสถานะ `viewOnly`
- ฟังก์ชัน saveGrade(studentId): ยิง POST '/index.php?page=update_grade' ส่ง `{ id: studentId, grade: newGrade }` ไปอัปเดตเกรดลงตารางฐานข้อมูลจริง พร้อมโชว์ Toast บันทึกสำเร็จ

2.4 ฟังก์ชัน "ดูรายชื่อนักศึกษา" (Read-only Student View Modal)
----------------------------------------------------------------------
- เมื่อคลิกปุ่มดูรายชื่อนักศึกษา ระบบจะทำการดึงข้อมูลนักศึกษาในวิชาเรียนปกติ แต่จะทำงานในโหมด `viewOnly = true`:
  * เปลี่ยนชื่อ Modal เป็น "รายชื่อนักศึกษา"
  * ซ่อนฟิลด์แก้ไขเกรด และซ่อนปุ่ม "บันทึกเกรดทั้งหมด" เพื่อความสะอาด ปลอดภัย และป้องกันการเขียนทับข้อมูลโดยไม่ตั้งใจ

----------------------------------------------------------------------
📂 ส่วนที่ 3: ระบบฐานข้อมูล MySQL (Database Schema & Mock Data Injection)
----------------------------------------------------------------------

3.1 แก้ไขข้อผิดพลาด Table not found
----------------------------------------------------------------------
- สร้างตารางเพิ่มใน MySQL Container เพื่อให้ระบบไม่เกิดข้อผิดพลาดในการ JOIN ข้อมูล:
  * ตาราง `clo` (รหัส CLO, subject_id, คำอธิบาย CLO)
  * ตาราง `enrollment` (รหัสลงทะเบียน, student_id, subject_id, grade)

3.2 เตรียมข้อมูลสำหรับการทดสอบ (Mock Data Injection)
----------------------------------------------------------------------
- จำลองการ mapping CLO ของแต่ละวิชาจำนวน 3-6 CLOs ทั้งหมด 73 วิชา (รวม 321 แถว)
- ลงทะเบียนเรียนจำลองให้นักศึกษาจำนวน 131 คน เข้าสู่ห้องเรียน 73 วิชา (รวม 1,210 แถว)
- ส่งผลให้วิชาสอนและการตัดเกรดดึงตัวเลขจำนวนและรายชื่อขึ้นแสดงผลได้อย่างถูกต้องสัมพันธ์กับ DB จริง

----------------------------------------------------------------------
📂 ส่วนที่ 4: การปฏิวัติโครงสร้างคำสั่ง SQL และชื่อตัวแปรหลังบ้าน (Refactoring)
----------------------------------------------------------------------

เพื่อแก้ไขระบบให้ตรงตามตารางจริงทางกายภาพ เพิ่มความเข้าใจง่ายในการพัฒนาต่อยอด ได้ดำเนินงานแก้ไขชื่อตาราง SQL และชื่อตัวแปรภายใน PHP ทั้งหมด 8 ไฟล์ดังนี้:

4.1 ไฟล์ components/Teacher/grading/get_grading_data.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `subjects` -> `subject` และ `enrollments` -> `enrollment`
- เปลี่ยนตัวแปร: `$sql_courses` -> `$sql_subject`, `$stmt_c` -> `$stmt_subject`

4.2 ไฟล์ components/Teacher/CoursesPage/get_my_courses.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `enrollments` -> `enrollment` และ `subjects` -> `subject`

4.3 ไฟล์ components/Teacher/CoursesPage/get_course_students.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `enrollments` -> `enrollment`

4.4 ไฟล์ components/Teacher/CourseStudents/get_course_students_clo.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `subjects` -> `subject` และ `enrollments` -> `enrollment`
- เปลี่ยนตัวแปร: `$stmt_sub` -> `$stmt_subject`

4.5 ไฟล์ components/Teacher/MyCourses/get_teacher_courses_overview.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `enrollments` -> `enrollment`
- เปลี่ยนตัวแปร: `$stmt_std` -> `$stmt_enrollment`

4.6 ไฟล์ components/Teacher/AssignInstructors/get_assign_data.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `enrollments` -> `enrollment`
- เปลี่ยนตัวแปร: `$sql_enroll` -> `$sql_enrollment`, `$stmt_enroll` -> `$stmt_enrollment`, `$enrollments` -> `$enrollment`

4.7 ไฟล์ components/Teacher/CourseReports/get_course_report.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `subjects` -> `subject` (ในจุด JOIN คำนวณสัดส่วนเกรดและผลสัมฤทธิ์ CLO)

4.8 ไฟล์ components/Teacher/CourseReports/get_report_filters.php
----------------------------------------------------------------------
- เปลี่ยนตาราง SQL: `subjects` -> `subject`
- เปลี่ยนตัวแปร: `$sql_courses` -> `$sql_subject`, `$stmt_courses` -> `$stmt_subject`, `$courses` -> `$subject` (โดยคีย์การตอบกลับ JSON ยังคงเป็น `"courses"` เพื่อความเสถียรของฝั่งหน้าบ้าน)

🧪 ผลการตรวจสอบและการันตีคุณภาพ (Validation & QA Results)
----------------------------------------------------------------------
- **ผ่านการตรวจสอบความถูกต้องของไวยากรณ์โค้ด (PHP Syntax Verification)** ด้วยคำสั่ง `php -l` ทุกไฟล์ข้างต้น 100% ปราศจากข้อผิดพลาดทางไวยากรณ์ (No syntax errors detected)
- **ระบบหลังบ้านและหน้าบ้านเชื่อมโยงถึงกันอย่างปลอดภัย** การประมวลผลดึงวิชา กรอกเกรด และแสดงกราฟรายงานสรุปทำงานได้อย่างถูกต้องและรวดเร็ว
