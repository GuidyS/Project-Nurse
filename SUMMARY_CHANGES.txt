========================================================================
             สรุปรายงานการปรับปรุงระบบและส่วนประกอบต่าง ๆ (Teacher Portal)
========================================================================

เอกสารนี้ระบุการเปลี่ยนแปลง โครงสร้างฐานข้อมูล (Database Schema), โค้ดหลังบ้าน (Backend API) 
และหน้าจอแสดงผลหน้าบ้าน (Frontend Pages) เพื่อย้อนกลับไปใช้โครงสร้างฐานข้อมูลดั้งเดิมที่มีเพียง "เกรด (Grade)" 
ในตาราง enrollment โดยถอดระบบการบันทึกคะแนนสะสมดิบและคะแนน CLO ออกทั้งหมดตามความต้องการของผู้เรียน

------------------------------------------------------------------------
1. 🗄️ การปรับปรุงโครงสร้างฐานข้อมูล (Database Schema Migration)
------------------------------------------------------------------------
ได้มีการรัน Migration คำสั่ง ALTER TABLE เพื่อ **"ลบ (DROP)"** คอลัมน์ที่เคยเพิ่มเข้ามาใหม่ออกจากตาราง `enrollment` โดยตรง:
  - ลบคอลัมน์ `raw_scores` (คะแนนดิบสะสม) -> ออกจากตาราง `enrollment` ถาวร
  - ลบคอลัมน์ `clo_scores` (คะแนนผลสัมฤทธิ์ CLO) -> ออกจากตาราง `enrollment` ถาวร

*ผลลัพธ์*: โครงสร้างตารางย้อนกลับสู่ความเรียบง่ายและเป็นไปตามความต้องการจริงของระบบสกีมาดั้งเดิม โดยเก็บเพียงรหัสนักศึกษา รหัสวิชา และเกรดที่ได้เท่านั้น

------------------------------------------------------------------------
2. 🔐 การปรับปรุง API ระบบหลังบ้าน (Backend API Endpoints)
------------------------------------------------------------------------

📂 [1] หน้ามอบหมายอาจารย์ (AssignInstructors API)
  - ไฟล์: `backend/src/components/Teacher/AssignInstructors/get_assign_data.php`
    * แก้ไขคิวรีสืบค้นจากฟิลด์ `prefix` ที่ไม่มีอยู่จริงในตาราง ให้ใช้งานคอลัมน์คำนำหน้าชื่อจริง `title` ในการเชื่อมต่อรายชื่ออาจารย์ (CONCAT) ช่วยลบข้อผิดพลาด 500 สำเร็จ
  - ไฟล์: `backend/src/components/Teacher/AssignInstructors/save_assign_instructor.php`
    * เพิ่มตรรกะรองรับการถอนคำสั่งมอบหมาย (Unassign) โดยหากระบุรหัสอาจารย์เข้ามาเป็นค่าว่าง จะทำการถอนสิทธิ์มอบหมายออกจากแผนการสอน JSON กลางโดยอัตโนมัติ

📂 [2] หน้าหลักการบันทึกเกรด (Grading API)
  - ไฟล์: `backend/src/components/Teacher/grading/get_grading_data.php`
    * ปรับปรุงคิวรีสืบค้นให้เอาฟิลด์ `raw_scores` ออก และเปลี่ยนมากำหนดค่าตัวแปร `scores` ดีฟอลต์เป็นค่าว่าง เพื่อส่งกลับให้หน้าจอหลัก (React) โหลดหน้าเว็บได้อย่างสมบูรณ์ไม่ติดขัด
    * ลบส่วนข้อมูลทดสอบจำลอง (Mockup) ออกทั้งหมด เพื่อให้อ้างอิงการแสดงผลเฉพาะนักศึกษาและสถิติข้อมูลจริงในระบบเท่านั้น
  - ไฟล์: `backend/src/components/Teacher/grading/save_grading_data.php`
    * ถอดตรรกะการแพ็กและบันทึกคะแนนสะสมดิบ JSON ออกทั้งหมด
    * พัฒนาระบบบันทึกข้อมูลเฉพาะ **เกรด (Grade)** ลงตาราง `enrollment` พร้อมรองรับการเพิ่มแถวลงทะเบียนนักศึกษาใหม่ (On-the-fly Enrollment Creation) อัตโนมัติในกรณีที่เป็นผู้เรียนจำลอง

📂 [3] หน้ารายวิชาที่สอน (CoursesPage API)
  - ไฟล์: `backend/src/components/Teacher/CoursesPage/api.php`
    * แก้ไข Case `get_courses` ให้ดึงทุกวิชาที่มีในตาราง `subject` และตัดสถิติ CLO ออก
    * ปรับปรุง Case `get_students` ให้ถอดคิวรี `raw_scores` ออกจากตาราง และส่งค่าคะแนน midterm, final, assignment เป็น `null` เพื่อไม่ให้ฝั่งหน้าบ้านเกิด Error
    * ปรับปรุง Case `update_grade` ให้ยกเลิกการเขียนบันทึกคะแนนสะสมดิบ โดยเขียนเฉพาะข้อมูล **เกรด (Grade)** บันทึกลงตาราง `enrollment` จริงเท่านั้น

📂 [4] การปรับปรุงไฟล์ระบบอื่น ๆ (Dynamic Path & Feature Reversion)
  - ปรับปรุงการระบุตำแหน่งอ้างอิงของไฟล์ระบบป้องกันความปลอดภัย (`auth_middleware.php`) ให้มีพิกัดโฟลเดอร์แบบ Dynamic (__DIR__) เพื่อป้องกันอาการหน้าเพจอื่นเปิดไม่ขึ้นหลังการเชื่อมเส้นทาง และถอดฟิลด์เก็บคะแนนดิบ/CLO ออกจากทุกไฟล์ที่เกี่ยวข้อง ดังนี้:
    * `get_teacher_courses_overview.php` (ถอดความคืบหน้าประเมิน CLO โดยเซตความคืบหน้า cloProgress เป็น 0)
    * `get_course_students_clo.php` (ถอด clo_scores ออก และตอบกลับ overall=0, status='pending' เพื่อความเสถียร)
    * `save_student_clo_scores.php` (ปรับฟังก์ชันเป็น No-op ตอบกลับบันทึกคะแนนสำเร็จทันทีโดยไม่ต้องบันทึกลงฐานข้อมูล)
    * `get_five_year_summary.php` (ยกเลิกการคำนวณ PLO ผ่าน clo_scores และคำนวณสถิติจำนวนผู้จบและ GPA สะสมเท่านั้น)
    * `get_course_report.php` (ยกเลิกการประมวลผลกราฟ CLO Achievement โดยส่งผลลัพธ์ cloAchievement กลับเป็นอาร์เรย์เปล่า)
