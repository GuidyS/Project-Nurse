# Faculty PDF storage

Per-user uploads go to:

`uploads/user-documents/{faculty_id}/`

Profile page shows PDFs from:

- Google Drive URLs in `faculty.description` (resume/history PDF)
- Admin-uploaded PDFs in `nursing_council_file`, `license_file`, `teaching_cert_file`

Legacy Excel image paths (`ข้อมูลบุคลากร test_Images/*.jpg`) are not displayed.

See `uploads/README.md` for the full layout.
