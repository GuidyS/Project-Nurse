# สรุปงาน 7 – 11 ตุลาคม 2569

งานชุดนี้ทำต่อจาก `ab280be` (กู้คืน 2 จุดที่หายตอน merge main 0.0.6)
เนื้อหาหลักคือ **ยกเครื่องสาย PLO → Sub PLO → CLO → คะแนน → ผลสมรรถนะ ให้เชื่อมกันทั้งระบบ**
พร้อมหน้าลงทะเบียนเรียนของนักศึกษา และปฏิทินภาคเรียนที่ตั้งค่าได้

> **อ่านก่อนดึงโค้ด:** มี SQL ที่ต้องรันด้วยมือ 1 ไฟล์ (ดูหัวข้อ [SQL ที่ต้องรัน](#sql-ที่ต้องรันกับฐานข้อมูลของเครื่องอื่น))
> นอกนั้นคอลัมน์/ตารางใหม่ระบบสร้างให้เองตอนเปิดหน้าครั้งแรก

## ภาพรวม: ข้อมูลไหลยังไง

```
[ประเมินสมรรถนะหลักแต่ละชั้นปี (YLO)]  ← Admin กำหนด Sub PLO ของแต่ละ PLO แยกตามชั้นปี
                 ↓
[จัดการหลักสูตร]  ← กำหนด YLO + เกณฑ์ผ่าน ให้แต่ละรายวิชา
                 ↓
[จัดการ CLO รายวิชา]  ← ดึง Sub PLO ของ YLO นั้นมาให้อัตโนมัติ + แบ่งคะแนนจากโควตา 100/วิชา
                 ↓
[วิชาที่รับผิดชอบ → บันทึกผลการเรียน]  ← อาจารย์ให้คะแนนราย Sub PLO
                 ↓
[ผลการประเมินสมรรถนะหลัก]  ← รวมคะแนน Sub PLO เดียวกันจากทุกวิชา → บรรลุ/ไม่บรรลุ → สรุปจบปี 4
```

คู่ขนาน: **[วิชาที่ลงทะเบียน]** ของนักศึกษา → สร้างแถวใน `enrollment` → อาจารย์เห็นนักศึกษาในหน้า "วิชาที่รับผิดชอบ" ทันที

## 1. โครงสร้างใหม่ของ PLO / Sub PLO / YLO

### เปลี่ยนอะไร

| เดิม | ใหม่ |
| --- | --- |
| Sub PLO กำหนดที่ปุ่ม "แก้ไข YLO" ในหน้าจัดการ CLO รายวิชา | กำหนดที่หน้า **"ประเมินสมรรถนะหลักแต่ละชั้นปี (YLO)"** ที่เดียว |
| YLO ของ CLO เลือกเองทีหลัง | YLO ผูกกับ **รายวิชา** ตั้งที่หน้าจัดการหลักสูตร |
| ตาราง matrix YLO×PLO ตั้งค่าแยก | ชั้นปีของ Sub PLO = YLO โดยตรง ไม่ต้องตั้งซ้ำ |

**รายการประเมินสมรรถนะ = Sub PLO** ระบบย้ายข้อมูลเดิมจาก `competency_items` มาเป็น `curriculum_sub_plo` ให้อัตโนมัติครั้งเดียว

### รหัส Sub PLO นับแยกตามชั้นปี

PLO1 ของชั้นปี 1 เริ่มที่ 1.1 และ PLO1 ของชั้นปี 2 ก็เริ่มที่ 1.1 เช่นกัน
เพิ่ม/ลบแล้วระบบจัดเลขใหม่ให้เฉพาะกลุ่ม (PLO + ชั้นปี) นั้น ไม่กระทบชั้นปีอื่น

> เพราะรหัสซ้ำข้ามชั้นปีได้ ทุกที่ที่แปลงรหัสเป็น id **ต้องระบุชั้นปีด้วยเสมอ**
> (`getSubPloIdMap($pdo, $frameworkId, $yearLevel)`) ไม่งั้น CLO จะไปผูกกับ Sub PLO ของชั้นปีอื่น

### หน้าจอที่เกี่ยวข้อง

**ประเมินสมรรถนะหลักแต่ละชั้นปี (YLO)** — เดิมชื่อ "จัดการรายการประเมินสมรรถนะหลัก"
- แก้ไขหัวข้อ PLO1–PLO8 ได้ทุกข้อ
- ปุ่ม "ลบทั้งหมด" รายข้อ PLO (ทุกชั้นปี) และปุ่ม "ลบทั้งหมด (PLO1–PLO8)"
- หลักสูตรยึดตามหน้า "จัดการหลักสูตร" ที่เดียว ไม่มี dropdown แยกอีก
  (PLO/Sub PLO ใช้ร่วมกันทุกรอบหลักสูตร)

## 3. จัดการ CLO รายวิชา

| ข้อ | เปลี่ยนเป็น |
| --- | --- |
| dropdown "เลือก YLO ที่สอดคล้อง" | ตัดออก — แสดง YLO ของรายวิชาให้เห็นแทน |
| ช่องนั้น | **"กำหนดคะแนนสำหรับ CLO"** + กล่องคะแนนคงเหลือ (อ่านอย่างเดียว เริ่มที่ 100/วิชา) |
| Sub PLO | ขึ้นบรรทัดละข้อ: `☐ 1.1 คำอธิบาย | คะแนน | คะแนนผ่าน` |

- คะแนนรวมของทุก CLO ในวิชาเดียวกันต้องไม่เกิน **100**
- คะแนนผ่านของแต่ละ Sub PLO ต้องไม่เกินคะแนนเต็มของข้อนั้น
- PLO ของ CLO คำนวณจาก Sub PLO ที่ติ๊ก ไม่ต้องเลือกเอง

## 5. หน้า "วิชาที่รับผิดชอบ" → บันทึกผลการเรียน

- ปุ่มจุด 3 จุด → เปลี่ยนเป็นปุ่ม **"บันทึกผลการเรียน"** ตรง ๆ กดครั้งเดียวเข้าหน้ากรอกคะแนนเลย (ตัดหน้าต่างดูคะแนนคั่นออก)
- **Sub PLO ทุกข้อของทุก CLO อยู่ในตารางเดียว** หัวตาราง 2 ชั้น (CLO → Sub PLO + คอลัมน์รวมของแต่ละ CLO + คะแนนรวม)
- **ชื่อวิชาด้านบนเป็น dropdown** สลับวิชาได้ และ **คะแนนที่กรอกค้างไม่หาย** กด "บันทึกทั้งหมด" ทีเดียวได้หลายวิชา
- กล่องกว้างเต็มจอ (95vw) หัว/ท้ายตรึง ตารางเลื่อนข้างใน — กดบันทึกได้เสมอแม้นักศึกษาเยอะ
- **แก้บั๊ก:** วิชาที่มีเฉพาะในหน้าจัดการหลักสูตร (ยังไม่มีแถวใน `subject`) เคยหายจากรายการ ตอนนี้แสดงครบ

**ไฟล์:** `CoursesPage.tsx`, `get_my_courses.php`

## 6. ผลการประเมินสมรรถนะหลัก

- ตัดช่องให้คะแนน 1–5 ออก เหลือป้าย **บรรลุ / ไม่บรรลุ / ยังไม่ประเมิน** คำนวณอัตโนมัติ (โหมดดูอย่างเดียว)
- เกณฑ์: รวมคะแนน Sub PLO ข้อเดียวกันจากทุกวิชา เทียบกับผลรวมคะแนนผ่าน → **PLO บรรลุเมื่อ Sub PLO ทุกตัวผ่าน**
- ชั้นปี 4 มีการ์ด **"สรุปผลเมื่อจบชั้นปีที่ 4"** รวมผลทั้ง 4 ปี (ปี 1–3 ไม่มี)
- ตารางรายข้ออยู่บน การ์ดสรุปอยู่ล่าง คอลัมน์แรกชื่อ **"สมรรถนะชั้นปีที่ N"**
- **หน้าของนักศึกษากับของอาจารย์ใช้ตัวคำนวณและ component แสดงผลตัวเดียวกัน** จึงตรงกันเสมอ

**ไฟล์:** `competency_result_helpers.php` (ใหม่), `CompetencyResultView.tsx` (ใหม่), `get_student_competency.php`, `get_my_competency.php`, `AdvisorCompetencyDetail.tsx`, `StudentCompetencyView.tsx`
**ลบ:** `save_student_competency.php` (ไม่มีการให้คะแนนด้วยมืออีกแล้ว)

- ตาราง **"รายวิชาที่ลงทะเบียน"** แสดงเฉพาะวิชาที่ลงแล้ว + ปุ่ม **"ลงทะเบียนวิชา"** มุมขวาบนเปิด pop up เลือกจากรายวิชาทั้งหมดของหลักสูตร

- วิชาที่มีเฉพาะในหลักสูตร ระบบสร้างแถว `subject` ให้อัตโนมัติเมื่อมีคนลงทะเบียนครั้งแรก

## 8. ปฏิทินปีการศึกษา — เส้นแบ่งเดียวทั้งระบบ

**เดิม** ปีการศึกษาฮาร์ดโค้ดเปลี่ยนที่ 1 เมษายน ซึ่งชนกับภาคเรียนที่ 2 (1 ม.ค. – 16 พ.ค.) ทำให้เทอมเดียวกันถูกนับเป็นคนละปีการศึกษา

**ใหม่** ปีการศึกษาเริ่มนับที่ **วันเปิดภาคการศึกษาที่ 1** ซึ่งตั้งค่าได้

| ภาคเรียน | ช่วงวันที่ (ค่าเริ่มต้น) |
| --- | --- |
| ภาคการศึกษาที่ 1 | 15 ส.ค. – 31 ธ.ค. |
| ภาคการศึกษาที่ 2 | 1 ม.ค. – 16 พ.ค. |
| ภาคฤดูร้อน | 17 พ.ค. – 14 ส.ค. |

ปีการศึกษา 2569 = 15 ส.ค. 2569 – 14 ส.ค. 2570 (ครอบคลุมทั้ง 3 เทอมต่อเนื่อง)

**หน้าที่ขยับตามเส้นแบ่งนี้:** รายงานระบบ, ส่งออกข้อมูลระบบ, คลังเอกสาร มคอ., จัดการนักศึกษา, แดชบอร์ด KPI คณะ, ภาระงาน 4 ด้าน, โครงการและวิจัย, สรุปข้อมูลสะสม 5 ปี / สรุปผลงานวิจัย 5 ปี

> **ข้อควรรู้:** ข้อมูลที่เคยบันทึกช่วง 1 เม.ย. – 14 ส.ค. ของปีก่อน ๆ **ไม่ถูกแก้ย้อนหลัง** ตัวเลขรายงานอาจเหลื่อมกับข้อมูลใหม่ ควรเช็กก่อนขึ้นเซิร์ฟเวอร์จริง

**ไฟล์:** `academic_calendar.php`, `academic_helper.php`, `get_academic_calendar.php`, `academicYear.ts`, `use-academic-year.ts`, + 8 endpoint ที่อ้างปีการศึกษา
