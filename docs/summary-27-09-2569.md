## 1. หน้าแก้ไขข้อมูลนักศึกษาของ Role Admin

หน้าจัดการผู้ใช้ฝั่งแอดมินถูกปรับให้เป็น **โหมดดูอย่างเดียว ยกเว้นช่องสถานะ**
และจัดหน้าตาให้เหมือนฟอร์มข้อมูลส่วนตัวที่นักศึกษาเห็นเอง

| หัวข้อ | ผลลัพธ์ |
| --- | --- |
| ชื่อ-นามสกุลไทย / อังกฤษ | อยู่บรรทัดเดียวกัน ทั้งฟอร์มนักศึกษาและอาจารย์ |
| ปีที่รับเข้าศึกษา | คำนวณจากรหัสนักศึกษา แก้ไขไม่ได้ |
| ชั้นปี | คำนวณอัตโนมัติ เลื่อนชั้นเองทุกปี แอดมินแก้ไม่ได้ |
| เกรดเฉลี่ย (GPA) | ตัดออก |
| โทรศัพท์บ้าน | ตัดออก แสดงเบอร์บิดา/มารดาแทน (อ่านอย่างเดียว) |
| ภูมิลำเนา | ตัดออก |
| ส่วนสูง / น้ำหนัก / BMI | นักศึกษากรอกเอง แอดมินดูได้อย่างเดียว |
| ที่อยู่ตามทะเบียนบ้าน | เปลี่ยนเป็น "ที่อยู่ปัจจุบัน" จากที่นักศึกษากรอก อ่านอย่างเดียว |
| วันที่จบการศึกษา | ตัดออก |

### สถานะแบบ Dropdown

- **นักศึกษา** — คงอยู่ / พักการเรียน / ลาออก
  ถ้าเลือกพักการเรียนหรือลาออก จะมีช่องเหตุผลให้เลือก (ฟิกไว้): ปัญหาการเงิน, ย้ายที่เรียน, ปัญหาสุขภาพ, โดนรีไทร์
- **อาจารย์** — คงอยู่ / ลาออก / เกษียณ (ไม่ต้องมีเหตุผล)

### การบังคับภาษาในช่องชื่อ

ช่องชื่อภาษาไทยรับเฉพาะอักษรไทย ช่องภาษาอังกฤษรับเฉพาะอักษรอังกฤษ
กรองทั้งฝั่งหน้าเว็บ (พิมพ์ผิดภาษาแล้วไม่ขึ้น) และตรวจซ้ำฝั่ง backend ก่อนบันทึก

### ปุ่ม "ตั้งค่าปีการศึกษา"

อยู่ข้างปุ่มนำเข้าข้อมูลในหน้าจัดการผู้ใช้ของแอดมิน ใช้ตั้งค่า

- **วันตัดรอบเลื่อนชั้นปี** (ค่าเริ่มต้น 10 สิงหาคม) เปลี่ยนวัน/เดือนได้
- **การลบข้อมูลนักศึกษาอัตโนมัติ** เปิด/ปิดได้ และกำหนดจำนวนปีได้ (ค่าเริ่มต้น 8 ปี)
  มีปุ่มดูจำนวนรายที่เข้าเกณฑ์ และปุ่มสั่งลบทันทีที่ต้องพิมพ์ยืนยัน

## 2. การแจ้งเตือน

เพิ่มการแจ้งเตือนเข้าหน้า "การแจ้งเตือน" 2 เรื่อง

1. **ใบประกอบวิชาชีพใกล้หมดอายุ** — เมื่อระบบเตือนอาจารย์ตามรอบเดิม (เหลือ 6 / 3 / 1 เดือน)

## 3. เกณฑ์ผ่าน (pass score) ของรายวิชา

เพิ่มฟิลด์ **เกณฑ์ผ่าน** ในหน้าจัดการหลักสูตรรอบ 5 ปี ของแอดมิน
ใส่เป็นคะแนน 0–100 ต่อรายวิชา ถ้าไม่กรอกจะใช้ค่าเริ่มต้นของระบบคือ **70**

ค่าเกณฑ์ผ่านถูกเชื่อมต่อไปยัง

- หน้า **ให้คะแนน** (Role Teacher) — สีคะแนนและข้อความ "เกณฑ์ผ่าน N คะแนน" ใช้ค่าจริงของรายวิชา
- หน้า **ผล CLO รายบุคคล** — ผลประเมิน ผ่าน/ไม่ผ่าน และสีของช่องคะแนน CLO ใช้ค่าจริงของรายวิชา

ตัวอย่างที่ทดสอบ: วิชา `103-111 ภาษาอังกฤษพื้นฐาน` ตั้งเกณฑ์ผ่าน 50
นักศึกษา `6603400002` ภาพรวม 55 คะแนน เปลี่ยนจาก "ไม่ผ่านเกณฑ์" เป็น "ผ่านเกณฑ์" ถูกต้องแล้ว

คอลัมน์ `pass_score` ในตาราง `curriculum_cycle_subject` สร้างเองอัตโนมัติเมื่อเปิดหน้าจัดการหลักสูตร ไม่ต้องรัน SQL เพิ่ม

## 5. รวมหน้าข้อมูลนักศึกษาในความดูแล (Role Teacher — งานที่ปรึกษา)

เดิมแยกเป็น 3 เมนู คือ ข้อมูลวัคซีนนักศึกษา / ข้อมูลสุขภาพนักศึกษา / ประเมินสมรรถนะหลัก
ตอนนี้ **รวมเหลือเมนูเดียวคือ "ข้อมูลสุขภาพนักศึกษา"**

ตารางรายชื่อเป็นแบบนี้

| รหัสนักศึกษา | คำนำหน้า | ชื่อ-นามสกุล | ข้อมูลวัคซีน | ข้อมูลสุขภาพ | ประเมิน |
| --- | --- | --- | --- | --- | --- |
| 6603400001 | นางสาว | ญาณันธร โอนอิง | ดูข้อมูล | ดูข้อมูล | ดูข้อมูล |

- คอลัมน์ **สถานะ** (Active / Graduted / Retired) ถูกตัดออก
- เพิ่มคอลัมน์ **คำนำหน้า** ดึงจากข้อมูลส่วนตัวของนักศึกษา (`student.title`)
- กดปุ่มไหนก็เข้าแผงนั้นของนักศึกษาคนนั้น มีปุ่มย้อนกลับมาหน้ารายชื่อ
- ความสามารถเดิมครบ รวมถึงปุ่มบันทึกผลการประเมินสมรรถนะ และลิงก์เปิดหลักฐานแนบของวัคซีน

### บั๊กที่แก้ไปด้วย: ค้นหาแล้วจอขาว

API ส่ง `student_id` กลับมาเป็น **ตัวเลข** แต่โค้ดตัวกรองเรียก `s.student_id.includes(...)`
ซึ่งใช้ได้กับ string เท่านั้น พอพิมพ์ในช่องค้นหาจึงเกิด `TypeError` แล้วทั้งหน้าหายไป
เป็นบั๊กเดิมที่มีอยู่ในทั้ง 3 หน้าก่อนรวม แก้โดยแปลงเป็นข้อความก่อนเทียบเสมอ
พร้อมกัน `full_name` เป็น null, ตัดช่องว่างหัวท้าย และไม่สนตัวพิมพ์เล็ก-ใหญ่

**ไฟล์ที่เกี่ยวข้อง**

- `frontend/src/components/pages/Teacher/AdvisorHealthRecordsView.tsx` (หน้ารวม)
- `frontend/src/components/pages/Teacher/AdvisorVaccinationDetail.tsx` (เดิม `AdvisorVaccinationView.tsx`)
- `frontend/src/components/pages/Teacher/AdvisorCompetencyDetail.tsx` (เดิม `AdvisorCompetencyView.tsx`)

## SQL ที่ต้องรันกับฐานข้อมูลของเครื่อง/เซิร์ฟเวอร์อื่น

โค้ดสองส่วนนี้แตะเมนูใน `system_sidebar_menus` ซึ่งอยู่ในฐานข้อมูล จึงต้องรันด้วยมือ

```bash
mysql -uroot -p MYSQL_DATABASE < backend/src/components/Teacher/CLOPage/remove_clo_management_menu.sql
mysql -uroot -p MYSQL_DATABASE < backend/src/components/Teacher/AdvisorStudentList/merge_advisor_student_menus.sql
```

- ไฟล์แรก — ลบเมนู "จัดการ CLO" และ permission `CLO_MANAGEMENT_VIEW`
- ไฟล์ที่สอง — ลบเมนู "ข้อมูลวัคซีนนักศึกษา" กับ "ประเมินสมรรถนะหลัก" (ฝั่งที่ปรึกษา)
  **ไม่ลบ** permission `VIEW_STUDENT_VACCINATION` / `MANAGE_COMPETENCY` เพราะยังใช้คุมขอบเขตผู้ใช้อยู่

ตาราง `system_settings` และคอลัมน์ `pass_score` สร้างเองอัตโนมัติ ไม่ต้องรัน SQL
