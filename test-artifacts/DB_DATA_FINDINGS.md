# รายงานสาเหตุ: หน้าเว็บไม่แสดงข้อมูลรายวิชา/นักศึกษา

**วันที่:** 26 มิ.ย. 2569 · **ฐานข้อมูล:** `MYSQL_DATABASE (26-6-2569).sql` (DB จริงของทีม) · **วิธีตรวจ:** query อ่านอย่างเดียว (ไม่แก้ไขข้อมูล)

## ข้อสรุปผู้บริหาร
หน้าเว็บ **เชื่อมต่อและอ่าน/เขียนฐานข้อมูลได้ปกติ** (ยืนยันจาก: login ได้, แสดงผู้ใช้จริง 11 คน, เขียน `audit_log` ได้ 208 แถว) — **ไม่ใช่ปัญหา DB เสีย และไม่ต้องลง XAMPP**

สาเหตุที่หน้าเว็บฝั่งอาจารย์ไม่มีรายวิชา/นักศึกษาแสดง คือ **ข้อมูล "เชื่อมโยง" ที่หน้าจอต้องใช้ยังไม่ถูกสร้างในฐานข้อมูล** (โดยเฉพาะการลงทะเบียนเรียนและการมอบหมายอาจารย์) ประกอบกับบั๊กโค้ดบางจุด

## สิ่งที่พบในฐานข้อมูลจริง
| ตาราง | จำนวนแถว | สถานะ |
|---|---|---|
| subject (รายวิชา) | 73 | ✅ มีข้อมูล |
| student (นักศึกษา) | 131 | ✅ มีข้อมูล |
| faculty (อาจารย์) | 94 | ✅ มีข้อมูล |
| **enrollment (การลงทะเบียนเรียน)** | **0** | ❌ **ว่าง** |
| grades (ตารางเกรดแยก) | 4 | ⚠️ มีข้อมูลแต่โค้ดไม่ได้ใช้ |
| curriculum_framework | 1 | ⚠️ ไม่มี `instructor_id` |
| audit_log | 208 | ✅ (พิสูจน์ว่าเขียน DB ได้) |

## สาเหตุราก (root cause)

**1. ตาราง `enrollment` ว่างเปล่า (0 แถว) — สาเหตุหลัก**
หน้าจอที่แสดง "รายชื่อนักศึกษาในวิชา" ทุกหน้า (CourseStudents, Grades, CoursesPage) ดึงข้อมูลด้วย `JOIN enrollment` และหน้ารายงานดึงปีการศึกษาจาก enrollment
→ เมื่อไม่มี enrollment เลย จึง **ไม่มีนักศึกษาแสดงที่ไหนเลยแม้แต่คนเดียว** แม้จะมีนักศึกษา 131 คนกับวิชา 73 วิชาในระบบ เพราะยังไม่มีอะไรเชื่อมว่า "ใครเรียนวิชาไหน"

**2. `curriculum_framework.mapping_json` ไม่มี `instructor_id`**
หน้า "รายวิชาที่สอน/รับผิดชอบ" หา "วิชาของฉัน" จากการจับคู่ instructor_id ↔ รหัสอาจารย์ใน JSON
→ เมื่อไม่มีการระบุว่าอาจารย์คนไหนสอนวิชาไหน จึง **ไม่มีวิชาขึ้นเป็น "วิชาที่ฉันสอน"** สำหรับอาจารย์ทุกคน

**3. ทดสอบด้วยบัญชี Admin (46172040)**
Admin ไม่ใช่อาจารย์ผู้สอน จึงไม่มีภาระงานสอน → หน้าฝั่งอาจารย์ว่างตั้งแต่ต้นเป็นปกติ (ต้องทดสอบด้วยบัญชีอาจารย์ที่มีวิชาในความรับผิดชอบ)

## ความไม่สอดคล้องของ schema (ทีมควรตรวจ)
- **เกรดอยู่คนละตาราง:** เกรดจริงเก็บใน `grades` (student_id, subject_id, grade_letter, grade_point, semester, year) แต่โค้ดอ่าน/เขียนเกรดที่ `enrollment.grade` → คนละแหล่งกัน
- **ตาราง `faculty` ไม่มีคอลัมน์ `user_id`** แต่หน้า MyCourses query `faculty WHERE user_id=?` → เกิด error 500
- **ไม่มีตาราง `clo`** แต่หน้า CLOPage ใช้ตารางนี้

## ผลกระทบต่อแต่ละหน้า (เฉพาะเรื่องข้อมูล)
| หน้า | ว่างเพราะ |
|---|---|
| รายวิชาที่สอน / รับผิดชอบ | ไม่มี instructor_id + ทดสอบเป็น admin (+ บั๊กโค้ด) |
| รายชื่อนักศึกษา / ผลสัมฤทธิ์ CLO / บันทึกเกรด | enrollment ว่าง → ไม่มีนักศึกษา |
| รายงานผลการศึกษา | enrollment ว่าง → ไม่มีปี/วิชาให้เลือก |

## ข้อเสนอแนะต่อทีม
1. **เติมข้อมูลการลงทะเบียนเรียน (`enrollment`)** — เชื่อม student ↔ subject ↔ ปีการศึกษา/เกรด (ผ่านฟีเจอร์นำเข้าข้อมูล หรือเพิ่มในระบบ) เป็นเงื่อนไขสำคัญที่สุดที่จะทำให้หน้าฝั่งอาจารย์มีข้อมูล
2. **ระบุอาจารย์ผู้สอนต่อวิชา** (`instructor_id` ใน curriculum_framework หรือผ่านหน้า "มอบหมายอาจารย์ผู้สอน")
3. **ตัดสินใจเรื่องแหล่งเก็บเกรด** ให้ตรงกัน (ใช้ `grades` หรือ `enrollment.grade` อย่างใดอย่างหนึ่ง) แล้วปรับโค้ดให้สอดคล้อง
4. **แก้บั๊กโค้ดที่บล็อกการดึงข้อมูล** (ดู `TEST_SUMMARY.md` หัวข้อ "ต้นเหตุหลัก")
5. ทดสอบซ้ำด้วย **บัญชีอาจารย์ที่มีวิชาสอนจริง** ไม่ใช่ Admin

> ย้ำ: ปัญหานี้ไม่เกี่ยวกับการติดตั้ง XAMPP หรือฐานข้อมูลใช้ไม่ได้ — ฐานข้อมูลพร้อมแล้ว เหลือ "เติมข้อมูลเชื่อมโยง + แก้บั๊กดึงข้อมูล"
